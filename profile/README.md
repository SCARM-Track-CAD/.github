# SCARM

> One named SCARM layout. Finish the section. Leave a note the next person can read.

## Session Card

| Slice | What you do in SCARM | What remains |
|-------|------------------------|--------------|
| Arrival | Open SCARM and name today's railroad desk | A titled 3D layout |
| Focus | Keep only live sections on the SCARM board | A short CAD pin list |
| Check | Read SCARM 3D layout before benchwork starts | A confirmed sectional track |
| Handoff | Mark finished sections inside SCARM | A note for the next visit |

## How SCARM Sits

SCARM does not replace the sectional boxes, the benchwork, or the 3D viewer you already use. It sits beside them as a named railroad desk for one job: which track CAD is live, which 3D layout still matches the sections, and what the next person should read before the next benchwork.

If two people share a layout PC, each keeps a SCARM style of their own. Extra yards wait for their own title instead of crowding the live CAD.

A first visit should be one short sectional pass, then the same SCARM desk the next day. That is enough to see if the 3D view holds.

## Traffic Light

| Signal | On the SCARM board | What you do |
|--------|----------------------|-------------|
| Green | Named CAD, short live section list | Continue the same 3D layout |
| Amber | Two yards mixed in one sectional file | Split the set before you build |
| Red | No title, no note, sections unlabeled | Stop and name the layout first |
| Clear | Handoff written, live sections few | Close SCARM and leave the desk |

## Open Order

1. Open the last SCARM track CAD, not a new empty railroad desk.
2. Read the section list and the last handoff.
3. Finish one visible 3D check inside SCARM.
4. Write what changed, then close with fewer unlabeled sections than you found.
5. If the set feels crowded, drop anything that belongs to a different SCARM yard.

## Desk Fit

| Who | What SCARM holds |
|-----|--------------------|
| Railroad desk | Track CAD and 3D layout for a railroad you own |
| Shared desk | One SCARM profile per person |
| Club room | Named sectional track waiting for benchwork |
| Support | A repeatable SCARM layout for the same sections |

## After a Week

A week in SCARM is not a thicker unmatched 3D pile. It is the same title, a shorter live section list, and a note that still makes sense before benchwork. Take finished yards off the live set so the next visit starts on the CAD that is still open.

## Sign-off

- [ ] The SCARM workspace name is short enough to scan
- [ ] Only the live sectional track is on the board
- [ ] A second person can read the handoff
- [ ] The last SCARM file still opens after a restart

## Field Note

SCARM is easier to trust when the railroad desk stays smaller than the sectional boxes it came from. Name the layout, keep the live CAD, finish one visible 3D pass, and write what changed.
